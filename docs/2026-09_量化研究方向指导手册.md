## 阅读指南（新手先读这三行）
1. **"能不能赚"从来不是看回测累计几倍，而是看它能否在样本外(OOS)稳定、抠掉成本、控住回撤地赚**（机构口径：IC/IR/夏普/月超额，见 §术语）。
2. **方向本身没有"注定能赚钱"的捷径**——机构真正的优势在 ①把主干做深 ②系统/数据/工程/纪律 ③避免过拟合 ④让每个 alpha 都"小而稳"。个人赢面不在更大模型，而在 ①独有/小众数据与时效 ②执行少犯纪律错 ③把一切当"候选、持续 OOS 换血"。
3. **本文每个方向都给了"由浅入深阶梯 + 怎么做才算数(门槛)"**——请按阶梯推进，别一上来就追最深的。

## OOS 到底是什么？（先讲清它，因为全文都会用它）
**OOS = Out-Of-Sample ＝「样本外 / 从未见过的一段」。**
- 机器学习/量化拟合模型时，用来“定下规律/调权重”的那段时间叫 **样本内（In-Sample, IS）**。模型很可能"背"下这段里的噪声，回测漂亮但那叫**过拟合**。
- 所以要用模型**从没用来训练/看过的另一段时间**（样本外 / OOS）来验它是不是“真找对规律”而不是"靠背答案考上”。
- **作用和意义**：它是分辨"真 alpha"与"回测幻觉"的唯一裁判。你挖因子/调参天然会在这段上无意识地挑好的；只有 OOS（且只验一次、不许改完再回来改）才能真正证明"换一批股票/换一个月份它还赢不赢"。这就是我反复强调"同一窗组合验证=考前看过答案、必须分窗OOS"的原因。

## 方向② 因子挖掘与"多因子"（你 021/022 已挖、也已证一部分）
**是什么**：挖能"把好的排前面"的排序力(IC)，再把多个**彼此独立**的排序合成更强的组合。
**机构怎么做**：机器/LLM 进掘几百上千因子 → 每只做过采样稳健的单因子评估(IC/ICIR/增量)→ 做 **冗余去重**(看两两月度IC时序相关, 相关性高只留一只)→ 保留"真·多重经济族"(价量/基本面/另类都各留代表)→ 组合优化合成 → 全流程OOS、逐因子衰变监控与换代。

**我从浅到深怎么走**：①先学"怎样才算一个'好的''有效'因子"(IC/ICIR/分位(单调)/独立/OOS增量→ 你已经会过六关/IR) ②学"冗余相关去重"的那一页(近0/负才算错峰、正高=同源)——你已在 §术语与之前文档做“相关诊断” ③真进阶时,找**与现有15簇近0/负相关且自带强度**的新数据族(不是再加反转/动量)。

## 方向③ LLM / 文本 → α（你 004 LLM 模拟盘，较浅）
**是什么**：把新闻 / 研报 / 分析师语气/公司公告这类非结构化文字,变成"今天到未来数日"的动量/情绪因子。
**机构怎么做**：数据独享(万得/彭博终端+付费另类)→ LLM提取事件与情绪时长→ 与"出现时点"对齐(防用未来信息)→ 低频稳健(作截面/事件套利因子)→ 与价量因子正交→ OOS 检验信息时效窗口。
**我个人怎么由浅入深**：①先用**已披露公告/龙虎榜/新闻时间点**(你 data/extra_features 有 news/cls/consensus/reports) 做"事件当日后未来5-20日超额"的**事件统计**(何时涨、认在即)（比“让LLM直接写涨跌”更诚实、少幻觉）→ ②把"事件类型/情感"用LLM打个低维标签再和价量错峰叠 → ③防look-ahead：**只用"已公开、且当天收盘后可用"的信息算，绝不要用未来**。
**一上手做哪一步**：别又造一个"看一个公司说利空它跌了"的幻影——先做**「事件清单 → 事件后超额形态」的诚实描述统计**(哪些事件类型真的能带来可交易、且能次日开盘进场的超额)。这才是机构事件的起点。
**怎么做才算数**：给"这条信息"能带来,且扣成本后、**次日能进场**、且不随时间被抢走的正超额才算；若只是"消息当天冲一下明天就回"，多半是已反映、不可交易，别当 alpha。

（重要小抄：小抄方向①③最容易造假=都用上**未来信息**或**另一只看似不同但同源**。只要一条新信号只能在自己回测窗对、一 OOS 或一实盘就掉，它就不是真 alpha。）

## 方向⑤ Kronos 等时序预训练（方向四你已 3a/3b 做过、多证伪）
**是什么**：不是"预训练=一定强",而是"大数据预训练 → 少量你的数据微调/零样本"。它**目标**是:用通用时间序列的"迁移",减少你这边样本不足。你已在方向四(3a 零样本、3b 微调)验证过,要诚实记得:证伪≠白做,你已学到"怎样严格判它是不是只是在学一个看涨算术均值"这类教训。
**机构会做/你由浅入深**：
1. 零样本当基线看它是否不靠你训练也能有信号(少坑)
2. 若基线不行,做"微调"；若微调后还是只在你的训练窗强就停止(证伪)
3. 真价值可能在你数据**稀疏/高频到无法自己训够**时
4. 用它做**择时/补样本(合成增强,** 你 121->129 用过合成序列)比"预测涨跌"常更稳
**我一上手做哪一步**：你已经把方向四收敛到一个结论。可把"要不要在 V4 主链正式接 Kronos"暂缓(你8-10已判 V4 不接合成/择时) →保持现决策即可。真正的下一步不在 Kronos 本身,而在于你想不想给“另一眼”能找并稳的迁移信号。
**怎么做才算数**：Kronos类要想在你这有价值,需 **它加在“已经相对干净基线上的净增IC/择时”是正、OOS 稳、非启发式均值回归**;而它大概率只在你样本极稀或做高频时才是。

## 方向⑥ regime/风格切换 建模（你 2025 年被风格翻脸教训过）
### 方向⑥ regime/风格切换 建模
**是什么**：量化 alpha 常"对一阵、错一阵"(如你 2025H1 被风格翻脸)。regime=学会"现在处于什么状态"(牛/熊/震荡、价值 vs 成长、大 vs 小…),用它对整套策略给出"信谁/停谁/满 or 空"的总开关——不是每天猜、不是只挑某段好看当月历。
**机构怎么做(逐层加深)**：①用多指数+波动+市场广度+风格价差做状态分类器 ②给每子模型/因子按状态存"平均胜率"表 ③上层出**总开关**(市场空头→整套降敞口/空头因子)+**风格调向**(当下更信价值 or 动量) ④严格 OOS(状态标签极易过拟合)。
**我由浅入深**：a) 先做"两态:强/弱行情",用强度+广度加一个总仓位开关 b) 再到"价值vs成长/大小盘状态"看是否该换风格 c) 最后才真 regime-aware 权重调参。
**一上手做哪一步**：别又加灰箱。先把现有 V4 **拆成"强势季度"与"弱势季度"两段的IC/超额**看——它到底在哪个状态掉链子(你会9/07分窗)。先把总开关调出来。
**怎么做才算数**：加上开关后**整体 OOS 年化IC不降、最大回撤明显降、不是只在某一状态靠运气赢**。若只是多了层 if 没整体稳健加分→别加(那是在定制某段)。
**补记**：(记录你做的状态定义/阈值/它把整体回撤/IC改善多少,别仅记"某月账面好了一点"。)

## 术语表（新手随手查）
- **Alpha/超额**：跑赢一个基准(如沪深300)的那部分收益。机构 alpha 现实量级 = 年化 3~15% 的"小而稳",不是回测里的 70-120%(那是摩擦为零+集中微盘+友好段的幻影)。
- **Beta**：跟着大盘整体涨跌的部分(不可回避,可用择时/仓管)。
- **IC / RankIC / 月度IC**：一只因子/一个预测和"未来相对超额"的(秩)相关。0=随机;单因子 0.03-0.06 才算'有效';你 V4~0.01-0.016=偏低但真。
- **ICIR（=IC均值/IC波动）**：看它够不够稳(不只是准)。看**组合时用IR**。
- **信息比率 IR**：年化超额 / 年化跟踪误差。0.5 扎实、0.75-1.0 很好、_1.0 顶级。你 70 月 A/B/C 回测 ~1.3-1.6 = 优秀级(但要"能带走/实盘打折")。
- **夏普**：年化超额/年化波动。1 不错、2 很好、3 真盘几乎无。别只看累计。
- **最大回撤**：账从最高到最低跌幅;决定你有没有人民币扛得住、会不会割在地板。
- **OOS（样本外）**：没参与训练/选择的独立一段,用来诚实验证(见文首)。
- **过拟合**：把噪声也背下来:回测漂亮,OOS/实盘掉。对策=分窗OOS、只验一次、少调参、留 holdout。
- **换手/交易成本**：调仓频率×成本;高频/小盘尤其要算。你看执行层文件(方向⑧)。
- **因子同步换仓/状态拥挤**：大家都在买同一类(如都低波/都动量)时边际掉。检'和现有簇相关'能发现。
- **回归经济族/冗余**：不同皮同源(都耦合同一量价/低关注)不算独立。判据=两两月度IC时序相关(>0.6 冗余;≈0/负 才是错峰可叠)。
- **数据线寿命/decay**：一个因子的超额不是永续,要按季/月回看近12月IC是否仍正,衰减了就换/停(你会写"换血")。
