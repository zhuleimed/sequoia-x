不存在"通吃 70 个月的唯一最优卖出政策"；**最优点随评估窗口的市况而移**。70月全样本里 C>B≫A，

## 6. Alpha 本质核验（2026-09-07 续）：V4 vs 沪深300 到底有没有真 Alpha、因何而生

### 6.1 基准几乎没涨——数值上 Alpha 极大，但需看 CAGR 而非字面倍数
真·沪深300(`index_daily.sh.000300`,与 labels.py 同基准)对齐 V4 回测窗 2020-08-31 base→2026-06-30：
CSI300(价格) 累计 **+3.4%**、年化 ≈ **+0.6%/y**（到 2026-09-04 更 −5.6%）。加 ~2%/y 红利 → 基准总回报 ~+15%/
~2-3%/y。而 V4 arm(A/B/C) CAGR ~69/119/112%。**此窗口基准本身 5.8 年近乎原地，故数值上 V4 显然"跑赢基准"，**
但判断真伪要看 CAGR/信号，不是"几千倍"这种吓人字面。

### 6.2 真信号吗？——测到"小但真实"的 OOS rank IC
`output/backtest_v2/monthly_ic_analysis.csv`(n=70)：**T2 IC 月均≈+0.011、60%月正；T4≈+0.016、61%月正**。
这正是真实世界强弱排序 IC 的量级 → **第一层结论：有、且是微弱可持续 edge（非幻觉）**。

### 6.3 停牌/涨跌停/成本约束核查——用户记的是对的，回测里已在
核 `monthly_engine.py` 实盘执行：买入检查**涨停跳过**(open≈前收×1.10)、**跌停跳过**、**滑点万1**、**整手100股**、
佣金封顶重算(L1014-1044)；卖出 开×(1−滑点)−佣金−印花税(L1076-1080)；停牌日无 bar→买入自然跳过。
抽查股票池符号**全为主板(6xx/00x，无 300/688/北证)** → 写死 ±10% 对主板为正确口径(非创业板±20%)。
⇒ **之前把"涨跌停缺失"列为放大器不成立，撤回。**

### 6.4 ② IC-explained CAGR 分解——能带走的真钱液位只在中低个~低两位数年化
用 idx_ret 逐月与 arm 收益算现实月超额：**A +3.8%/mo、B +6.5%/mo**，负超额月仅 20-23/70。但**纯 IC(0.011-0.016)
在真实流动中盘能解释的月度 top-选出超额仅 ~+0.15~0.4%/mo → 单低两位数年化**(cross-section σ_cs 3%~8% 也就 ~2-5%/y)。
⇒ 回测 70-120%/y 明显远高于 IC 纯解释 → 主体是"顶部微小盘极端动量 + 理想 fill"放大，非 IC。

### 6.5 ③ 去前视隔离——前视**不是**这个放大器的来源（推翻最初假设，要客观）
同一引擎 canonical('prediction_cache.json' 73月) vs **去前视 V4('prediction_cache_v4_nolook.json' 70月)**，A/B 两臂：
| 臂 | canonical | 去前视V4 | canonical−去前视 |
|---|---|---|---|
| A现状 | +2066%/2.65 | **+3635%/3.20** | **−1569pp / −0.55 夏普** |
| B纯持有 | +9553%/2.75 | **+32135%/3.49** | **−22582pp / −0.74 夏普** |
去前视缓存反而**更高收益、更高夏普**（两者差异还含建模差异，不止前视轴，因 nolook 缓存重建另改特征 dim）。M 但方向确凿：**canonical 并没有被前视"虚高"**；反而更稳的 canonical 是偏低、非偏高那侧。＋ A 臂独立核对(外部 summary_all +2077% ≈ 本 +2066%)。⇒ **机制与前视双轴都脱责**。

### 6.6 收敛结论（诚实分层）
- **有真 Alpha**：基准 0.6-3%/y 之上，模型 OOS rank IC ≈ +0.011~0.016(60%月正)是真实微弱 edge；去前视后回测更高不更低。
- **但 70~120%/y 是摩擦为零、净值取向的极端 top-微盘动量在友好 2020-21 + 温和近端的复合**，**不等于活钱期望年化**。
  IC 液位(中低~低两位年化)才更像能带走的可持续真钱；高 CAGR 相对 IC 的放大，主体来自"顶部微小盘极端动量 +
  理想 fill"。但需如实收敛（用户补正，2026-09-07）：
  - **资金口径=100万**(现盘 INITIAL_CAPITAL 100万/10只=10万/只；回测与实盘同)。A/B 是等权比例，**各 %收益/CAGR/夏普与资金额无关**(结果 % 在 500k 与 100万 相同，仅 ¥ 翻倍)——故上面所有 % 结论对 100万 直接成立。
  - **买=开×滑点万1、卖=开×(1−滑点)已在**。在 100万/10万只/主板多数名字里，10万单相对日成交额占比极小 → 开盘+万1滑点已基本如实刻画成交，失真已大幅收窄。残留**仅限被选中的极稀薄低成交尾个股**(10万足以扰动其开盘)——比早先笼统说"冲击全未建"要窄得多（修正我的夸大）。
- **判真金唯一裁判 = 实盘/模拟盘 OOS**：当前 V2 实盘(8/3 起, ~满仓 under C)样本太短，需≥数月至过一轮牛熊逐步定夺。
- **勿拿 70-120% 当活钱年化预投**：本课题资金 100万/10万只，开盘+万1滑点已如实，失真主要仅在极稀薄尾个股。故对 100万 级，可把它当成"偏高但已抠掉显性成本"的上界去看，真期望年化仍按 IC 液位(单~低双位)估；若要再保守，对所选极稀薄股挡掉即可。
