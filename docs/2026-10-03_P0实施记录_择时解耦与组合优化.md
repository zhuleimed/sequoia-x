## 二、关键发现

### 2.1 `market_exposure` 曾经"算了但没生效"（代码级）

**位置**：`risk/sizer.py` → `monthly_engine._execute_monthly_buy`

```python
# sizer 算了含市场择时的 budget：
sig["budget"] = base_budget × w × market_exposure   # market_exposure = 市场状态建议仓位

# 但回测买入只用 weight，把 market_exposure 丢了：
available = budget_per_stock × weight                # ❌ 市场择时系数没进买入
```

**修复**：
- `sizer.size_positions` 额外输出 `sig["exposure"]`
- `_execute_monthly_buy`：`available = budget_per_stock × weight × exposure`
- M3：移除"只在 is_extreme 减 TOP_N"，改为**按 `advised_exposure`（0.3/0.5/0.7/1.0）连续写入 exposure**

### 2.2 对照回测证明：**该修复对收益几乎无影响**

| 版本 | 年化 | 总收益(6个月) | 夏普 |
|------|------|--------------|------|
| 旧版（改前） | +452.88% | — | 4.55 |
| 新版（改后） | +452.49% | +119.64% | 4.67 |

→ **说明 M5（全风控）的效果主要来自 IC加权/波动率权重（`weight`），而非市场状态择时**
→ **该修复无害，无需回滚**

### 2.3 ⚠️ 我的判断错误（重要教训）

**我一度认为"风控从未生效"并想回滚** —— 依据是一份**很旧的回测 json**（5种风控模式收益完全相同，-48.59%）。

**实际**（查 `BACKTEST_PLAN.md` + 项目记忆 `final-backtest-results.md`）：
- **历史 2026-07-31 已修复过风控**（四项修复：市场状态前视、T1 AUC硬编码、T2+T4动态权重、T2分布空仓预警），累计贡献 **+28.2%**
- 最佳配置 **M4(+IC加权) + TOP_N=10**，全周期 11 个月 **+89.5%**、夏普 3.35
- 我看到的那份 json 恰是**修复前**的状态（`BACKTEST_PLAN.md` 记为"❌ 风控完全失效"，属**历史现象**）

**教训**：**不能凭一份旧结果文件就断言"某功能从未生效"** —— 应先查历史记录/记忆/文档。

## 三、2026-03 单月 +64.5% 异常排查（结论：非数据问题）

### 3.1 现象
回测月度收益：`2026-03 = +64.53%`（单月），异常高。

### 3.2 排查过程与结论
| 检查 | 结果 |
|------|------|
| 回测价格 vs 数据库 | ✅ **完全一致**（非数据错误） |
| 600396 价格轨迹 | **2026-03-16~03-25 连续约8个涨停**（每日+10%）→ 3.30→8.35（**+153%**） |
| 涨停序列合规性 | ✅ 每天+10%（符合A股涨跌停规则），成交量正常 |
| **前视偏差** | ✅ **无**（2月末预测 t2=0.4319 → 3月2日买入开盘3.30 → 月末卖8.35） |
| 可成交性 | ✅ 买入日未涨停（买得进）、卖出日非涨停（卖得出） |

**结论**：**数据真实、逻辑成立**。600396 在 3 月**恰好连续涨停**。

### 3.3 ⚠️ 但暴露真正问题：**收益高度集中**

| 指标 | 值 |
|------|-----|
| 总收益（6个月） | **+119.7%** |
| **剔除最赚1只** | +84.5% |
| **剔除最赚2只** | **+59.1%**（腰斩） |
| 剔除最赚3只 | +48.2% |
| **前2只占总盈亏** | **51%** |
| 单笔收益中位数 | +7.1% |
| 月度中位数 | +4.71% |

→ **一半收益来自2只"连续涨停"股** → **运气成分大、可复制性存疑**
→ 这解释了**"回测好、实盘差"**的部分原因（连续涨停股实盘可能买不进/停牌/次日回落）

## 四、新增的评估指标（已可用）

**位置**：`monthly_engine._compute_final_metrics`

```python
"return_ex_top1/2/3"      # 剔除最赚 1/2/3 只后的收益率（判断可复制性）
```
