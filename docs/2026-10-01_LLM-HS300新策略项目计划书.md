## 二、现状分析（原 LLM 策略链路）

```
pipeline.py (18:10)
  └─ Step strategy: main.py
       ├─ 1. 8个量化策略各自选股 → strategies_results {策略名: [股票]}
       ├─ 2. MarketAnalyst.analyze(strategies_results)
       │      · 用 Counter 统计"多策略重叠频率" → 取 top10 喂 LLM
       │      · LLM 多维度分析（大盘/外盘/舆情/基本面）→ 推荐 2 只
       ├─ 3. save_llm_recommendations(db, ..., top_n=2) → 写 sim_buy_signals
       └─ 4. 推送 LLM 研判报告
  └─ Step simulation: main.py --sim-update
       └─ SimEngine(sequoia_v2.db).run_daily() → 买卖/估值/日结/日报
```

**关键复用点**：
- `SimEngine`（`sequoia_x/simulation/engine.py`）：买卖/估值/止损/日结 —— **完全复用**
- `MarketAnalyst`（`sequoia_x/analysis/analyst.py`）：LLM 分析 —— **复用，但需改候选池来源**
- `save_llm_recommendations` / `save_strategy_results`：信号写入 —— **复用/适配**

**与原策略的唯一差异**：候选池来源（8策略 → 沪深300成份股）。

## 八、实施记录（2026-10-01 完成）

### 8.1 最终架构（重要：与原计划的差别）

**⚠️ 原计划设想"给 024 加独立 cron，与 004 同时启动"——已被用户更正并废弃。**
用户明确：**只 004 拉数据；024 等 004 同步完成后，就着原 LLM 策略的位置启动**。

最终实现：**024 不再是独立 cron，而是作为 004 管线 sync 之后的步骤被调用**。

```
004 管线（cron 不变: 10 18 * * 1-5 … 004_sequoia-x … pipeline/pipeline.py）
  1. sync                数据同步              ← 只有 004 拉数据
  2. llm_hs300(024)      LLM-HS300选股         ← 就着原 LLM 策略的位置，从 004 库取数
  3. sim_hs300(024)      HS300模拟盘日结        ← 独立库 sim_hs300.db
  4. v2_simulation       V4 模拟盘操作          ← 不受影响
  5. strategy_summary    策略汇总推送
```

→ **无需新增任何 cron**；024 不自己拉数据、不自己启动。

### 8.8 LLM 采样温度（2026-10-01 定稿）
- 实测：同一天(09-30)数据、同样候选，`temperature=0.3` 时 4 次选股**全不同**；`temperature=0` 时 3 次有 2 次一致（高置信标的 000568 稳定）。
- **决定：采用 `temperature=0`**（`Hs300Analyst` 默认值），提高选股稳定性/可复现性。
- 说明：`temperature=0` 仍非 100% 确定（LLM 服务端固有非确定性），但已显著优于 0.3；
  用户明确**不额外加"当日结果缓存"**。

### 8.9 提示词设计（2026-10-01 定稿）

**演进历程**（提示词是本策略的核心，经多轮打磨）：
1. 初版：仅"单日数据"（收盘/涨跌/PE/PB/成交额）；
2. 加"防追高"：发现单靠措辞无效（LLM 看不到历史位置）→ **补历史维度**（近5日/20日涨幅、距60日高点）；
3. 修正失衡：原 prompt"严禁追高"占篇幅过大 → LLM 只挑跌得多的（可能选垃圾股）
   → 改为 **"两步法"（先排除风险，再多维优选）** + 平衡原则（"位置低≠值得买"）；
4. **完善总概**：确立**六段式结构**（角色任务 / 选股哲学 / 字段字典 / 选股方法 / 待选数据 / 输出要求）；
5. **补充维度**（本地数据支持）：增加 **行业 / 市值 / ROE** → "质地"从"仅凭PE/PB推断"变为 **ROE 实证**，
   并支持 **PE×ROE 结合判断性价比**。

**当前 prompt 结构（六段）**：
```
【一、角色与任务】      资深分析师 + 明确目标
【二、选股哲学（总纲）】 ① 风险优先 ② 多维平衡 ③ 安全边际
【三、数据说明】        字段字典（12字段，含 ROE/距高点含义）
【四、选股方法 — 两步走】 第①步排除（追高+亏损/负PE）→ 第②步四维优选
【五、待选数据】        299 只（12字段/行）
【六、输出要求】        第①步说明 + 逐只四维理由 + RECOMMEND 行
```

**字段清单（12维）**：代码 / 名称 / 行业 / 市值 / ROE / 收盘 / 当日涨跌 / 近5日 /
近20日 / 距60日高 / PE / PB / 成交额。
prompt 约 **39,300 字符（~2.6万 token）**。
