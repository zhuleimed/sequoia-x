# LSTM 模型选股 V2 — 设计文档

> 版本: v2.0 | 日期: 2026-07-23 | 状态: 已确认

## 一、背景与目标

### 1.1 问题

原 LSTM-Transformer 模型（`model_selection/`，v1.3）存在根本性缺陷：

- 训练时报告的 Rank IC = 0.1575，但在 495 天回测中的真实样本外 Rank IC 均值仅 **-0.0117**
- 模型预测分布严重偏差：96.2% 的预测值为负（均值 -0.06）
- 回测全周期亏损 -19.8%，与训练指标完全矛盾
- 根因：训练 IC 在极窄的时间窗口上计算（最后 2 个交易日），不代表泛化能力

### 1.2 目标

在独立子目录 `model_selection_v2/` 下从零构建新的股票收益率预测模型，严格满足：

| 指标 | 最终目标 |
|------|:-------:|
| 样本外 Rank IC 均值 | > 0.08 |
| 样本外 Rank IC 最低值 | > 0 |
| 回测年化收益率 | > 15% |
| 回测夏普比率 | > 1.0 |
| Walk-Forward IC>0 比例 | > 70% |

### 1.3 策略

分两阶段：

- **Phase 1（树模型验证期）**：用 XGBoost/LightGBM/CatBoost 快速迭代，验证特征和标签有效性
- **Phase 2（深度学习优化期）**：Phase 1 达标后，用多任务深度网络追求更高 IC

## 三、多任务标签设计

### 3.1 三个预测目标

| 任务 | 类型 | 标签定义 | 模型 | 用途 |
|------|------|---------|------|------|
| T1 短期方向 | 二分类 | `sign(close[T+5] - close[T])` → 0/1 | XGBoost | 决定买不买 |
| T2 中期收益 | 回归 | `(close[T+20]/close[T] - 1) - (idx[T+20]/idx[T] - 1)` | LightGBM | 决定买多少 |
| T3 风险度量 | 回归 | 20日日收益率年化波动率 | CatBoost | 决定仓位上限 |

### 3.2 标签构建规范

- 严格避免 look-ahead：ref_date=T 时，所有标签使用 T+1 到 T+N 的数据
- 停牌跳过：如果未来 N 日数据不足（连续停牌），该样本不生成标签
- 异常值裁剪：收益率在 [-0.5, +0.5] 范围内（涨跌停极限），波动率 < 2.0

## 四、训练数据构建

### 4.1 数据来源

- 主数据库：`data/sequoia_v2.db` 的 `stock_daily` 表
- 指数数据：沪深 300（`000300`）日线

### 4.2 采样策略

| 参数 | 值 | 说明 |
|------|-----|------|
| 股票池 | ~3000 只 | DataEngine.get_base_stock_pool() |
| 时间覆盖 | 2020-01-01 ~ 2026-07-20 | ~6.5 年 |
| 采样频率 | 每季度 6-8 天 | 每月取 2 天（月初+月中），同一天对全量股票采样 |
| 单日样本数 | ~3000 | 取决于当天有数据的股票数 |
| 预计总样本 | ~50 万 | 3000 × 26 季度 × 7 天 |

### 4.3 训练/验证/测试切分

使用 `labels.py` 中的 `build_training_dataset()` 函数：

1. 遍历所有采样日期，构建特征矩阵 X 和标签向量 y1/y2/y3
2. 按时间顺序排列（日期由早到晚）
3. Walk-Forward 评估时动态切分，不预先固定比例

### 4.4 数据质量

- 排除 ST/\*ST 股票（通过 stock_list 表标记）
- 排除上市不足 120 交易日的次新股
- 排除近 20 日日均成交额 < 100 万的流动性不足股票
- 缺失特征用 0 填充（已在 features.py 的 Z-score 归一化中处理）

| 新增特征组 | 维度 | 内容 |
|-----------|:---:|------|

## 六、模型架构

### 6.1 Phase 1：三个独立树模型

#### T1: XGBoost 分类器（5日涨跌方向）

```
目标: 二分类 (0=跌, 1=涨)
损失: binary:logistic
评估: AUC + 准确率
关键超参:
  - max_depth: Optuna 搜索 [3, 12]
  - learning_rate: [0.01, 0.3]
  - n_estimators: early_stopping_rounds=50
  - subsample: [0.6, 1.0]
  - colsample_bytree: [0.6, 1.0]
  - reg_alpha / reg_lambda: [1e-3, 10]
  - scale_pos_weight: 自动平衡正负样本
```

#### T2: LightGBM 回归器（20日超额收益率）

```
目标: 回归 (超额收益率)
损失: huber (delta=0.1)
评估: MAE + RMSE + Rank IC
关键超参:
  - num_leaves: Optuna 搜索 [15, 255]
  - learning_rate: [0.01, 0.3]
  - n_estimators: early_stopping_rounds=50
  - min_child_samples: [10, 100]
  - subsample: [0.6, 1.0]
  - colsample_bytree: [0.6, 1.0]
  - reg_alpha / reg_lambda: [1e-3, 10]
```

#### T3: CatBoost 回归器（20日波动率）

```
目标: 回归 (年化波动率)
损失: RMSE
评估: MAE + RMSE
关键超参:
  - depth: Optuna 搜索 [3, 10]
  - learning_rate: [0.01, 0.3]
  - iterations: early_stopping_rounds=50
  - l2_leaf_reg: [0.1, 10]
  - random_strength: [0.1, 10]
```

### 6.2 超参数搜索

使用 Optuna（与旧模型相同的搜索框架），但：
- 每个模型独立搜索，n_trials=50
- 搜索目标：验证集 Rank IC（对分类器用 AUC）
- 时间序列交叉验证：TimeSeriesSplit(n_splits=3)
- 搜索结果持久化到 `data/models/v2_selection/optuna_t1/t2/t3.db`

### 6.3 Phase 2：多任务深度学习（待 Phase 1 达标后设计）

占位目录 `deep/`，初步方向：
- 共享特征提取器（LSTM/Transformer/CNN）
- 3 个独立任务头
- 联合损失 = λ1·BCE + λ2·Huber + λ3·MSE

## 七、Purged Rolling Walk-Forward 验证

### 7.1 验证流程

```
时间线: 2020 ─── 2021 ─── 2022 ─── 2023 ─── 2024 ─── 2025 ─── 2026
                                                          
Fold 1: [训练 2020-2023]           → 测试 2024            
Fold 2: [训练 2020-2024 Q1]        → 测试 2024 Q2-Q4      
Fold 3: [训练 2020-2024]           → 测试 2025            
Fold 4: [训练 2020-2025 Q1]        → 测试 2025 Q2-Q4      
Fold 5: [训练 2020-2025]           → 测试 2026 H1         
Fold 6: [训练 2020-2026 Q1]        → 测试 2026 Q2 (至今)  
```

### 7.2 Purge 规则

- 训练集最后一个采样日与测试集第一个采样日之间至少间隔 **22 个交易日**（覆盖 T2/T3 的最长预测窗口 20 日 + 2 日缓冲）
- 防止标签重叠：训练样本的标签预测窗口（最长 20 日）不得延伸入测试集时间范围
- 实现方式：`labels.py` 按日期排序后，`evaluate.py` 找到第一个测试日，向训练方向回退 22 日作为"禁止区"，该区域样本全部丢弃

### 7.3 评估指标

每期 Fold 报告：

| 指标 | 计算方式 | 目标 |
|------|---------|:----:|
| Rank IC (Spearman) | corr(pred_rank, actual_rank) | > 0.08 |
| 分类准确率 | (TP+TN) / Total | > 55% |
| 方向胜率 | 预测涨的股票中实际涨的比例 | > 55% |
| IC > 0 比例 | 所有 Fold 中 IC>0 的比例 | > 70% |

### 7.4 最终评估

所有 Fold 完成后，汇总报告：
- Rank IC 均值、标准差、最小值
- 各 Fold 的分类准确率和方向胜率
- 按年份/市场状态分组的 IC（牛市/熊市/震荡市各自表现）

## 八、回测

### 8.1 回测引擎

参照原 `model_selection/backtest/engine.py`，新建独立版本：

```
逐日循环 (T):
  1. 加载 3 个模型的最新预测结果（使用 T-1 日收盘数据构建特征）
  2. 综合买入信号:
     a. T1 预测涨概率 > 0.55 → 候选池
     b. 按 T2 预测超额收益率降序排序
     c. T3 预测波动率 → 动态调整单只仓位 = 基础预算 × (1 / max(vol_pred, 0.15))
     d. 取前 top_n_buy_per_day 只，扣除已持仓
  3. T+1 开盘价执行交易（先卖后买，滑点万1）
  4. 日终按收盘价估值
  5. 卖出规则：复用 sequoia_x/simulation/rules.py 的 evaluate_exit + 新增 V2 特有规则：
     - T1 预测跌概率 > 0.7 → 加速卖出（+20分）
     - T2 预测超额收益 < -3% → 加速卖出（+15分）
```

### 8.2 回测参数

| 参数 | Phase 1 默认值 |
|------|:-----:|
| 初始资金 | 50 万 |
| 最大持仓 | 10 只 |
| 单只基础预算 | 5 万 |
| 每日最大买入 | 2 只 |
| 滑点 | 万 1 |
| 佣金 | 万 2.5 |
| 印花税 | 千 1（卖出） |

### 8.3 回测期间

| 期间 | 描述 |
|------|------|
| 2024 全年 | 震荡市（HS300 +1.71%） |
| 2025 全年 | 大牛市（HS300 +34.94%） |
| 2026 至今 | 快牛（HS300 +24.25%） |
| 全周期 | 2024-01-01 ~ 2026-07-20 |

## 九、里程碑与决策门

| 阶段 | 条件 | 通过后动作 |
|------|------|-----------|
| 第一轮训练 | 代码完成，Walk-Forward 跑通 | 分析特征重要性，进入特征扩展 |
| 第一轮评估 | Rank IC 均值 > 0.02 | 进行特征扩展（+10 维），重新训练 |
| 第二轮评估 | Rank IC 均值 > 0.05 | 启动回测验证 |
| 第三轮回测 | 回测年化 > 5%，夏普 > 0.5 | 启动 Phase 2 深度学习设计 |
| 最终验收 | Rank IC>0.08，年化>15%，夏普>1.0 | 接入模拟盘，启用 cron 调度 |

每个决策门不通过则分析失败原因，调整方案后重新来过。

## 十三、风险与对策

| 风险 | 对策 |
|------|------|
| 纯量价特征无预测力 | 第一轮评估即能发现，IC≈0 则考虑引入基本面数据源 |
| 树模型过拟合 | Walk-Forward 天然防止，每期独立测试 |
| 数据量太大，内存不足 | 分批构建特征，逐批 concat，192GB 内存足够 |
| CatBoost 在 CPU 上太慢 | 降为 LightGBM 替代，三模型统一框架 |
| 分类标签不均衡 | XGBoost scale_pos_weight 自动处理 |
| 市场结构性变化 | Walk-Forward 覆盖多周期，能检测 IC 衰减趋势 |
