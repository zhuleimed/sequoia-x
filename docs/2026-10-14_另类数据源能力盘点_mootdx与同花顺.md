# mootdx 与同花顺 —— 另类（非行情）数据能力盘点（2026-10-14）

> **起因**：用户要求汇总"mootdx 和同花顺接口能拉取什么**符合本项目研究质量**的另类数据"。
> **方法**：不照抄文档 —— **逐个端点实测**（同花顺官方契约 `llms-full.txt` 共 104 个 REST 端点；mootdx 直接调库）。
> **判定标准（四关，来自 2026-10-14 研报侦察的教训）**：
> ① **历史够长**（能过样本外验证）② **样本够大** ③ **事件时点干净**（防前视）④ **不是已有数据的重复**（真·独立经济族）。
> **一句话前提**：**"当日快照"型数据再多也不能回测** —— 这是本次盘点的核心筛子。

---

## 〇、总结论（先看这个）

**两个接口能提供的"新另类数据"比预期少得多，且最有价值的几条都卡在"历史太短"上。**

**真正过四关的只有 3 条**：

| # | 数据 | 来源 | 历史 | 项目现状 | 性质 |
|---|---|---|---|---|---|
| **①** | **涨停池**（连板数/封单额/涨停原因） | 同花顺 | **2020-08 起（~6.2 年）** | **只有 1 年**（2025-08 起） | 量价族·**补历史** |
| **②** | **基金持仓**（机构持股明细） | 同花顺 | **~2013 起** | 无 | **真·独立经济族** |
| **③** | **mootdx 财务全量**（585 字段 × 119 期） | mootdx | **1990 起** | 已采 405MB，**未接入** | **真·独立经济族** |

**同时确认了一批"不能用的"**（详见 §三）——记下来避免重复踩坑：

- **端外直接禁用**：同花顺"资讯事件库"、"资金流历史" —— `code=2004`「该数据为同花顺AI客户端专用」
- **只有 1 年**：龙虎榜、热度榜、个股排名走势、跌停池、炸板池
- **只有当日快照（无任何历史）**：集合竞价、异动原因、连板天梯、火箭股
- **mootdx 的 F10**：只有 1 个栏目"最新提示"（一段文本），**无历史、不可回测**

### ★ 自查更正：`block` 的 "398,342 行" 是我读错了（2026-10-14 当日复查）

本文件初稿在 mootdx 表里写 `block` 返回 **398,342 行**、并据此怀疑"项目 `tdx_block` 仅 3,039 行 ⇒ 可能只存了子集"。
**当日复查后确认：这个怀疑是错的，398,342 行里绝大多数是解析错位的垃圾数据。**

证据（`api.block()` 返回的 DataFrame，4 列 = blockname/block_type/code_index/code）：

| 证据 | 实测 |
|---|---|
| `block_type` 有 22 种取值，但**只有 `block_type=2` 的板块名是正常中文** | 其余 21 种的名字含 `\x00` 空字节，如 `'18\x00601669'`、`'\x00003021\x000'` |
| 非 type=2 的行，`code` 列**只有 7.2%** 是标准 6 位数字 | 长度分布：**47% 为空、45% 为 7 位** ⇒ 字节错位（真代码被截断+串位） |
| 每个"板块"的行数恒定 | 12336 / 12592 / 12848 这类可疑整数，且 `code_index` 每块都从 0 重来 |
| code 列样例 | `'5\x0060011'`、`'9\x0060014'` —— 真代码应是 60011x / 60014x |

**⇒ 真实情况**：`api.block()` 里**真正解析成功的只有 `block_type=2` 那一类，共 20 个板块、3,180 原始行（去重后 3,056 个 (板块,代码) 对）**。
其余 395,162 行是解析器在二进制边界上错位产生的垃圾 —— **不是"我们没存的板块"，是"根本没有的板块"**。

**⇒ 项目 `tdx_block`（3,039 行 / 20 个板块）是完整的、正确的**（2026-07-24 采集）。
与实时数据逐板块对比：**20 个里 16 个完全一致**；仅 3 个区域主题板块有差异
（海南自贸 +1、海峡西岸 +3、粤港澳 +13，合计 +17）——**是 3 个月内的正常成分变动，不是数据丢失**。

**⇒ 顺带结论（对"板块数据能否做成因子"很重要）**：mootdx 能给的就这 **20 个板块**
（宽基指数 8 个：上证50/中证A50/中证A100/沪深300/创业板指/深证成指/深证50/科创50/北证50/精选指数；
主题概念 10 个：一带一路/专精特新/融资融券/粤港澳/雄安新区/海峡西岸/上海自贸/海南自贸/通达信88；
风险类 1 个：ST板块）——**没有行业板块、没有全量概念板块**。
⇒ 想用"行业/概念板块归属"做因子，**mootdx 给不了**，得另找源。

复现：
```python
from mootdx.quotes import Quotes
api = Quotes.factory(market='std', server=('180.153.18.170', 7709))
b = api.block(symbol='600519')
b[b['block_type'] == 2]['blockname'].nunique()          # → 20（真数据）
b[b['block_type'] != 2]['code'].astype(str).str.fullmatch(r'\d{6}').mean()  # → 0.072（垃圾）
```

---

**⇒ mootdx 结论**：**它没有"新的另类数据"**。它的另类能力就是**已经采下来的 585 字段财务**（1990 起、119 期、一手财报）。
这是本项目**唯一一条"长历史 + 大样本 + 公司一手 + 未接入"**的独立经济族数据 —— 对应待办 #8 里的"**非量价基本面**"。

## 二、同花顺（Financial-API）能力盘点

契约来源：`https://fuyao.aicubes.cn/llms-full.txt`（2026-10-14 拉取，11,882 行，**共 104 个 REST 端点**）。
各域端点数：A股核心 30 ｜ **基金 58** ｜ 期货 21 ｜ 期权 6 ｜ 指数 4 ｜ 资讯 1 ｜ meta 2。
调用限制：官方称"不限制累计调用次数"，但**单实例每秒 5 次**超限返回 `code=4001`。

### 2.1 ✅ 可用 + 有长历史（过四关的候选）

| 端点 | 实测历史 | 项目现状 | 字段 |

## 四、三条候选的价值评估（按"是否真独立经济族"排序）

| 候选 | 历史 | 是否独立经济族 | 主要风险 |
|---|---|---|---|
| **③ mootdx 585 字段财务** | 1990 起 | ✅ **是**（一手财报，非量价非分析师） | 已采未接；**"加列"路线已被 9-26 结构性约束判死**（训练窗仅 1.8 采样日 ⇒ 慢变量零增益）⇒ 只能走**事件层**（如"财报超预期/财务质量突变"事件） |
| **② 基金持仓** | ~2013 起 | ✅ **大概率是**（机构资金行为） | ①公开披露、**季报滞后 15 天** ②"抱团"是众所周知的拥挤因子 ③需聚合全市场约万只基金 ⇒ 调用量大 |
| **① 涨停池补历史** | 2020-08 起 | ⚠️ **否**（属量价族） | 是"**补历史**"不是"换血"；且项目**龙虎榜事件研究已两次证伪**（同类情绪事件）⇒ 期望值应放低 |

**⚠️ 对 ① 的重要提醒**：涨停/连板属**量价族（情绪面）**，不是独立经济族。它的价值在于**让已有的涨停事件研究从 1 年扩到 6 年**（提高统计功效），
而不是提供新信息。项目在此类事件上**已有两次证伪记录**（龙虎榜：整体不可交易、窄条件样本外归零）⇒ **应作为"评估能力提升"项，不是"抬天花板"项**。

## 五、复现口径

```python
# 同花顺：统一用一个 helper 探测任意端点
import os, requests
KEY = os.environ["HITHINK_FINANCE_API_KEY"]
def ths(path, **p):
    return requests.get("https://fuyao.aicubes.cn"+path, params=p,
                        headers={"X-api-key": KEY}, timeout=25).json()

# ① 涨停池历史边界（2020-07-15 无 / 2020-08-03 有）
import datetime
ms = lambda d: int(datetime.datetime.strptime(d,"%Y-%m-%d").timestamp())*1000
ths("/api/a-share/special-data/limit-up-pool", date_ms=ms("2020-08-03"), size=3)

# ② 基金持仓历史（2010-06-30 无 / 2013-06-30 有）
ths("/api/fund/portfolio/stock-history", thscode="510300.SH",
    report_type="quarter", end_date="2013-06-30")

# ③ 端外禁用证据
ths("/api/a-share/capital-flow/historical", thscode="600519.SH",
    interval="1d", start=ms("2021-01-01"), end=ms("2021-06-01"))   # → code=2004
```
