# 本轮研究结项报告（2026-10-13）

> **一句话**：我们没能找到"更赚钱"的方法；但**把"为什么找不到"量化成了可执行的判据**——
> 以后任何提案，**先算它预期的效应量**，小于本项目分辨下限（**MDE ≈ 1.5%/月，年化 18%**）的**不必跑**（跑了也只会得到"测不出"）。
>
> **一句话版本（给自己的提醒）**：不是不努力，是**这套数据的分辨率不够**；下一步该修的是"尺子"，不是"再加几列特征"。

---

## 一、本轮要回答的三个问题

1. 给模型**加特征/换结构/改融合**，能不能让策略更赚钱？
2. 收益为什么**总被极少数股票主导**？（待办 #46 现象）
3. 接下来**该往哪个方向投入**？

## 二、做了什么 + 每项的一句话结论

| 实验 | 结论（一句话） |
|---|---|
| V6-A：+5 维同花顺财务质量（134 维） | 等权下"B 比 A 好 26 个点"，**换生产口径变"差 30 个点"** ⇒ 方向随口径翻转，且都**没到显著** |
| V6-B / V6-C：删列（120 / 132 维） | 两条链**0/20 显著**（"测不出差异"） |
| V6-D：删死列 + 加 14 维财务深度（143 维） | 点估计更差（赢 1/24），按月**0/20 显著** |
| V6-E：再加 16 维股东/机构（159 维） | 点估计更差、按月 **0/20 显著** ⇒ **第 6 次撞同一面墙** |
| 通道消融（T2 / T4 两路） | 五项对比**全不显著** |
| **#46 归因（六步）** | **选股层没有可靠信息**：头部第 1~10 名 ≈ 第 11~20 名（**p=0.94**）；剔掉每月冠军，69 个月月均 **+0.94% → −1.63%**；对 6 把尺子（等权/上证50/沪深300/中证500/中证1000/上证综指）**全不显著**；CAPM alpha **符号随尺子翻转** |
| **#50 种子抖动探针** | **同一配置、只换随机种子：6 个月收益摆动 27~49 个百分点**（模型预测相关系数仅 0.055） |
| #56 / #61 组合层对照 | **扩持仓不降集中度**（集中度只由"单票上限"决定，机械量）；成本与持仓数无关（都≈2%/年） |
| #57 复核 #20（最小方差 vs 等权） | 原数字**可复现**，但"最小方差最优"**未过显著性**（三臂 p=0.17~0.29）、**方向依赖臂** |
| **#58 评估分辨率** | **MDE ≈ 1.5%/月（年化 ≈18%）** ⇒ 效应小于它的改动**在本项目根本测不出** |

## 三、能可靠说的（结论）

1. **选股层没有可证实的选股能力**（六步归因，多重独立证据一致）；
2. **任何"月频、组合层"的改动，效应 < ≈1.5%/月 就测不出**（不是"没有"，是"测不出"）；
3. **集中度只由"单票上限"决定**（权重口径机械量：上限 15% ⇒ 前 2 大 30%；上限 10% ⇒ 前 2 大 20%）；**扩持仓数不改变它**；
4. **收益靠少数月份的极端个股**（这也是"换种子就摆动几十个点"的机制）；
5. **唯一能用算术保证的改善类别 = 组合 / 权重 / 集中度 / 成本**（不靠运气）。

## 四、**不能**说的（避免以后重犯）

- ❌ 不能说"那 5 / 14 / 16 维没用"——只能说**测不出**；
- ❌ 不能说"等权比最小方差好 / 反之"——两者在本项目**分不出高下**；
- ❌ 不能说"止损规则不好"——**这块根本没测过**（它属"未检验"，不是"已否定"）；
- ❌ **不能拿单次回测的高低当结论**（种子一换就变，摆动 27~49 个百分点）。

## 五、为什么测不出（三个物理原因）

| 原因 | 数字 |
|---|---|
| **独立样本少** | 月频 × 69 个月 = 只有 69 个独立样本 |
| **月度波动大** | 组合月度差的标准差 ≈ **4.4%** |
| **收益集中** | 前 2 只股票能占 20~40% 的盈亏 ⇒ "总收益"这个指标本身不稳 |
| ⇒ 要分辨 **+1%/月**（年化 12%）的超额，需要 **153 个月（12.8 年）**；要分辨 +0.5%/月 需 **613 个月（51 年）** | |

## 七、下一步的门槛（**做任何新研究之前必须先过**）

1. **先估效应量**：新提案预期能带来多少 %/月？
   - **< 1.5%/月 ⇒ 不跑**（除同时升级评估手段）；
2. **要"测得出来"，只能先修尺子**（按性价比）：
   - ① **换评估对象**：日频/个股层（独立样本 69 → 数千）、选股层 TOP-N 超额 + 抗极端指标；
   - ② **多种子平均**（摊薄模型随机性）；
   - ③ 多市场/多资产（扩大独立样本）；
3. **流程**：`exp_contract.py`（preflight → smoke → postflight）+ 五项纪律（多种子 / 双口径 / 抗极端 / 三臂方向 / 按月配对 p 值）；
4. **可以立刻做、且不需要 MDE 的**：组合/风控/成本层的**机械改善**（如本次的持仓数与单票上限），判据用**权重口径**，并**先在模拟盘观察 1~2 个月**。

## 九、一句话收尾

**我们这一轮最大的产出，不是"更好的策略"，而是"知道自己不知道什么"，以及"下一次要怎样才能真的知道"。**
