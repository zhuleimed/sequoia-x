# 特征"时效性"与训练窗口的结构性约束（2026-09-26）

> 起因：在核对"龙虎榜/研报/事件面是否已纳入 129 维"时，实测了**每一组扩展特征
> 在时间轴上的非零覆盖率**，结果推翻了一个此前反复出现的乐观判断——
> "接入了新数据面 = 多了新信息"。本文把这条约束写清楚，并列出待决策项。

## 二、【重大更正】约束的真实形态：训练窗口其实只有 **~2 个采样日**

> ⚠️ 本文初稿（同日上午）的结论是"训练集跨 6 年 → 新数据源只能覆盖 2%"，据此
> 建议"改训练窗口"。**当日下午追查 V4↔V5 选股对拍为何近零相关时，发现该前提是错的。**
> 下面为更正后的版本，原结论已作废。

### 事实

`scripts/build_prediction_cache.py:509-516`：

```python
# 抽样 5000
MAX_TRAIN_SAMPLES = 5000
if n_train > MAX_TRAIN_SAMPLES:
    X_tr = X_tr[-MAX_TRAIN_SAMPLES:]     # ← 取按「日期→股票」排序的**尾部 5000 行**
```

样本按「日期→股票」排序，**每个采样日约 2,825 个样本** → **5000 行 ≈ 最后 1.8 个采样日**。

实测（2026-09 那个模型，v5 缓存）：

```
训练窗口(12个月) n_train = 71,319 个样本（约 24 个采样日）
截断后实际用于训练的采样日 = ['2026-08-07', '2026-08-21']   ← 只有 2 天
```

**即：所谓"12 个月滚动窗口"是被算出来之后**丢掉**的；每个月的模型实际上只用了
最近约 2 个采样日（≈ 最近 3~4 周）的横截面在训练。**

注：V4 代码含**完全相同**的 `MAX_TRAIN_SAMPLES = 5000`（`_v4ref` worktree 实测），
故这是全系统长期属性，不是本轮引入。

### 这条事实一次性解释了此前各自成谜的四件事

1. **V4↔V5 选股几乎零重合**（TOP50 交集 0，Spearman −0.019）：两个模型各自拟合
   ~2 个采样日的横截面，训练集小且高度同期相关 → 拟合结果对数据/特征的微小差异
   **极度敏感**，两次拟合落在完全不同的地方。
2. **预测 90% 为正**：v5 缓存的最后两个采样日月均 y2 都是正的（08-07 +3.97%、
   08-21 +3.61%）→ 模型学到"就是涨"。（V4 最后两天是 07-07 +4.46%、07-21 +11.05%，
   同样为正，故 77% 为正。）
3. **OOS IC 弱（T2≈0.011）**：2 个同期采样日无法支撑 15,480 维特征空间，泛化差。
4. **"月度重训加不了多少"**：有效窗口每次只前移约 1 个采样日。

### 对前文"特征时效性"的正确解读

之前担心的"新数据源只覆盖 146 个采样日里的 2%"**在效果上不成立**——因为训练根本
不用那 146 天。真实情况是：

- `dragon_tiger` / `limit_up`（覆盖最后 2~4 个采样日）→ **实际覆盖率接近 100%** ✓
- 所以"新数据面没效果"**不能**归因于覆盖不足；更可能是**训练窗口过短**导致模型
  根本没能力学到这些维度的规律（2 天样本 vs 上万维特征）

## 三、对 consensus（研报一致预期，5 维）的结论（更正版）

**仍建议撤回"按月留档"方案，但理由换了：**

**真正的理由是"训练窗口短于快照间隔"**：有效训练窗口只有 ~1.8 个采样日，而采样日
是每月第 5 / 第 15 个交易日 —— 同一次训练用到的 2 个采样日**必然落在同一个月内**，
因此**只可能落在同一份快照之后**，consensus 在这 5000 个样本上**恒为同一个值**
→ 树模型无法在其上分裂 → **零信息增益 → 依然是死列**。

要让它有机会，前提是**训练窗口能跨两个快照日**（即窗口 ≥ 1 个月）。这直接把问题
从"数据采集"转回"训练窗口"。

（初稿写的"覆盖率 8%、要 5~6 年"是**错误**的，一并作废。）

## 四、由此改写"提升"的路线（更正版）

**头号问题不再是"数据不够"，而是"训练窗口只有 ~2 个采样日"。**

### 路线 A（**新的第一优先级**）：还原训练窗口
把 `MAX_TRAIN_SAMPLES` 从 5000 提到真实窗口（如全部 71,319，或至少 20,000~30,000），
或改为**分层抽样**（每采样日抽固定条数，保证时间跨度）而非取尾部。
- **代价**：单月训练时间约 ×14（5,000 → 71,319 样本）
- **必须先做对照实验**：同一月、两种训练规模，比 OOS IC / 选股稳定性
- **可能还要配合**：特征维度高（15,480）与样本量（5,000）严重失衡，
  单靠加样本未必够，可能需要同时做特征降维/选择

### 路线 B：找**自带历史**的数据源
（此条不受影响，仍是有效方向）
- `mootdx_finance`（119 期，1990–2026，585 字段/期）✅ 自带历史，现成候补
- `reports`（东财研报，4,346 只 / 77MB）：带日期但**稀疏**（每只中位 9 条）且**陈旧**
  （多数股票最后一条停在 2025-08）⚠️ —— 需先评估覆盖度
- 注意：`reports` 目前**采集了但从未接进特征工程**（`FEATURE_GROUPS` 里没有它）

### 路线 C：短周期模型（原路线 B，**降级**）
- 原设想"短周期模型让近期数据源有用武之地"——**但现在已经是短周期了（1.8 个采样日）**，
  所以这条**不再成立**，降级为备选。
