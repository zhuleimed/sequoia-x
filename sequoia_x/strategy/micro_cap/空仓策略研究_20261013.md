## 一、结论先行

**空仓策略确实有效，而且效果很大 —— 但它有明确的"能力边界"。**

| | 年化 | **最大回撤** | Calmar |
|---|---|---|---|
| 不空仓 | 16.0% | **−42.4%** | 0.38 |
| **S3 拥挤度空仓** | **19.5%** | **−27.9%** | **0.70** |

**S3 把回撤砍掉 14.5 个百分点，同时年化还高 3.5 个百分点。**

**但经过 27 种替代方案的系统扫描 —— 没有任何一个能打败 S3。** 所以**不是"还没找到更好的"，
而是 S3 已经探到了这类信号的天花板**（见第四节）。

## 三、★ 回撤事件拆解（这一节最关键）

把 10 年历史里所有「回撤 > 15%」的事件逐个列出来（阈值 −15%，互不重叠）：

| 无空仓：峰值→谷底 | 深度 | 月数 | → | 加 S3 后同一事件 | 加 S3 后的深度 |
|---|---|---|---|---|---|
| **2017-10-11 → 2019-01-31** | **−40.9%** | 15.4 | → | **直接消失**（S3 期间全程空仓） | — |
| **2024-01-04 → 2024-07-10** | **−39.6%** | 5.9 | → | **直接消失** | — |
| 2017-10-11 → 2019-08-09 | −34.6% | 21.4 | → | 大幅压缩 | −25.4% |
| 2024-01-04 → 2024-03-05 | −29.6% | 1.8 | → | 消失 | — |
| 2026-01-23 → 2026-07-22 | −26.4% | 5.6 | → | **没挡住** | **−26.4%** |
| 2024-12-12 → 2025-01-06 | −21.3% | 0.8 | → | 没挡住 | −21.3% |

**而加 S3 之后，最大的几段回撤里 S3 的空仓占比是：**

| 加 S3 后的最大回撤 | 深度 | **S3 空仓占比** |
|---|---|---|
| 2019-04-19 → 2019-08-09 | **−26.6%** | **0%** |
| **2026-01-23 → 2026-07-22** | **−26.4%** | **0%** |
| 2024-12-12 → 2025-01-06 | −21.3% | 0% |

### 怎么读这三段

1. **S3 精准挡住了它该挡的**：2017-2019 的大熊市（−40.9%）和 2024-01 的微盘崩盘（−39.6%）
   **两次都直接消失** —— 这正是"微盘独立崩盘 / 系统性熊市"，S3 的设计目标。
2. **剩下的回撤，S3 空仓占比全是 0%** —— 它不是"没挡好"，是**从头到尾没触发**。
3. **`2019-04~08`** 是 **S3 解除空仓、重新进场后**遭遇的回调（2019 年初大涨→4月见顶→贸易战）。
4. **⚠️ `2026-01~07` 的 −26.4% 是最近的一次，S3 同样全程没触发** —— **值得警惕的近期风险**。

## 四、S3 的能力边界（本报告的结论）

```
S3（拥挤度空仓）擅长：  系统性熊市 / 微盘独立崩盘（有"钱在跑"的特征）
S3 管不到：            普涨之后的普通回调（没有拥挤特征，也没有系统性下跌）
```

**⇒ 那剩下的 −26.6% / −26.4% 是「另一类风险」，靠"空仓"这条路径天生解决不了。**
这也解释了为什么第二、三节里 27 种替代方案全部失败 ——
**它们都是在用"空仓"这把锤子，去敲一颗不属于它的钉子。**

**要再降这一段，必须换维度**（见下节）。

## 五、下一步（按可行性排序）

| # | 方向 | 说明 | 维度 |
|---|---|---|---|
| 1 | **选股端降 beta / 低波动筛选** | 剩下的大回撤是"普涨后回调"，本质是**高波动/高 beta 暴露** ⇒ 从选股源头压低 | 选股 |
| 2 | **买回机制（分批建仓）** | S3 解除后"立刻满仓"⇒ 若紧接着二次下跌就白挨（2019-04 正是这个形态）。可研究快慢确认/分批 | 空仓（执行） |
| 3 | **降低单只极端权重** | 30 只里若有个别股贡献了大部分回撤 | 持仓 |

> ⚠️ 注意第 2 项与 V3 里失败的"半仓"**不是一回事**：
> 半仓是**长期压低暴露**（所以拖累收益）；
> 分批建仓是**只改变"重新进场"那几天的节奏**，不影响正常期的暴露。
